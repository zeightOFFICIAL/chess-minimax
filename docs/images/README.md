# Screenshots

Drop the images referenced by the root `README.md` here, using these exact filenames:

| File | What to capture |
|------|-----------------|
| `hero.png` | Mid-game board, a piece selected so move hints are visible |
| `start-screen.png` | The hotkey/help screen shown before the game starts |
| `move-hints.png` | Close-up of a selected piece, enlarged, with its highlighted destinations |
| `check.png` | Board with the "King is under check!" banner visible |
| `promotion-menu.png` | The four-piece promotion chooser |
| `castling.png` | Before/after of a kingside castle (or just the castled position) |
| `end-screen.png` | The win/draw screen with elapsed time |
| `visual-sets.png` | Default set and `visual_set=1` side by side |
| `search-tree.png` | Diagram of the alpha-beta search tree with a pruned branch |
| `benchmark.png` | Chart of nodes/time per difficulty level |
